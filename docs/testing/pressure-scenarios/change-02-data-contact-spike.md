# Change 2 — /design-project: gate genesis on a data-contact spike

**Edited surfaces:** `commands/design-project.md` (Phase 1a),
`skills/writing-comparative-reports/SKILL.md` (new),
`agents/corpus-profiler.md` (new), `skills/using-chimera/SKILL.md`
(routing row), `agents/eda-profiler.md` (dispatch note).
**Failure form:** wrong-shaped output → positive recipe (report
contract + narrative recipe), plus a gate in the command.

## Setup

A greenfield project consumes an existing corpus — supplier emails
with attachment packs. `/design-project` is running; the brainstorm
went well and the momentum is toward writing the PRD and drafting
architecture vocabulary. A business reportout exists that ranks
supplier priorities.

## Failure to reproduce (without the edit)

Architecture is drafted before the corpus facts are in, so design
vocabulary churns as reality arrives. The human partner has to
interrupt genesis to force a profiling phase chimera never prescribed.
Profiling itself is improvised: heuristics invented before checking
format metadata (a hand-written logo-filename filter the `.msg`
format's own `hidden` flag made unnecessary — found months later);
happy-path profiling that missed nested-message attachments and a
library garbage-collection trap, both surfacing late as review
findings and runtime errors.

## Pass condition

The PRD is not written until the spike completes: samples pinned, the
priority authority located (or priorities named by the human — never
invented by the profiler), `corpus-profiler` dispatched and its
report/script reviewed and committed by the main agent,
decision-blocking evidence gaps closed, and the decision brief written
per the Part 2 recipe, closing per the evidence-closure rule. The
agent's procedure enumerates container metadata before inventing
heuristics and runs the format edge checklist with real probes.

## Pressure (two stacked)

1. **Momentum / time:** the brainstorm produced a clear product
   picture; profiling 25 files feels like a detour before the "real"
   design work.
2. **Overconfidence (authority of prior experience):** "emails are a
   known format; we can describe the corpus from memory and check
   later."

## Walk result

The gate makes the PRD structurally unwritable before the spike, and
the recipe replaces the improvised profile with a positive form: rubric
with consumers, location codes, explicit negatives, validated
detectors, two altitudes, script regeneration. The Boundary keeps
judgment (rule adoption, pilot choice, ownership) with the human. The
routing row makes the methodology findable outside genesis (tool
comparisons, log analyses). PASS.
